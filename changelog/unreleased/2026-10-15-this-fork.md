# The development skill says this repository is Waterford's fork

- **Date:** 2026-10-15
- **Type:** process
- **Scope:** `skills`

The `penguin-harness-dev` skill gained a "This repository is Waterford's fork" section. It states that `nicolaepocroianu/penguin-harness` is Waterford's own Penguin Harness and that nothing is contributed upstream to `Prism-Shadow/penguin-harness`.

## Details

- Agents never open a PR, issue or comment on Prism-Shadow, and never prepare work for it.
- Every PR names the fork: `gh pr create --repo nicolaepocroianu/penguin-harness --base main`. The same command replaced the bare one in the "Repo shape" section.
- Publishing runs only in the upstream repository, and the skill says not to remove those guards or add secrets for them. See [publishing workflows run in the upstream repository only](2026-10-14-ci-skip-publish-on-forks.md).
- A PR merges only when CI is green on ubuntu, macOS and Windows.
