# Who made each composition and critique

- **Date:** 2026-10-10
- **Type:** feat
- **Scope:** `web`

The Scene video section's list of compositions now says which agent made each one (its coding
agent, else its Penguin agent) and which look it was made in. A critique says which agent wrote
it. On test16, the same scene scored 2.4 when GPT-5.3-codex composed it and 3.6 when the Claude
coding agent did, so the agent behind a version is worth seeing when comparing them.
