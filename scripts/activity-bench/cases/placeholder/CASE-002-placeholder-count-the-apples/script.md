# PLACEHOLDER: Count the apples

This is a placeholder case for building and testing the activity bench. It is not a real case.

Three apples hang on a tree. The narrator asks: "How many apples are there?"
The child chooses from the numbers 2, 3 and 4. A wrong number makes the apple wobble and the
narrator says: "Count again." Choosing 3 makes the apples drop into a basket and the narrator
says: "Three apples!" The activity then ends.
